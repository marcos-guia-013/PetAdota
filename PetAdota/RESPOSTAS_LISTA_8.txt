QUESTÃO 1

Ao digitar http://localhost:8000/produtos/42/, o navegador envia uma requisição HTTP GET ao servidor Django. O Django procura no urls.py a rota que corresponde ao caminho e captura o valor 42. Em seguida chama a view ligada a essa rota, passando o request e o valor capturado. A view busca o registro no banco por meio do Model, monta o contexto e chama o render() com um template. A DTL processa o template, gera o HTML e a view devolve uma HttpResponse, que o navegador exibe.

a) O urls.py compara o caminho solicitado com as rotas cadastradas, captura os parâmetros da URL (aqui, o ID 42) e encaminha a requisição para a view correspondente.

b) A view recebe obrigatoriamente o objeto request (HttpRequest), além dos parâmetros da rota. Ela deve retornar um objeto HttpResponse, normalmente criado por render().

c) A função get_object_or_404(). Se o produto 42 não existir, ela dispara automaticamente a exceção Http404 e o Django responde com a página de erro 404, sem quebrar o site.

QUESTÃO 3

polls/views.py:

from django.shortcuts import render, get_object_or_404
from . import models

def detalhes_animal_view(request, pk):
    animal = get_object_or_404(models.Animal, pk=pk)
    contexto = {"animal": animal}
    return render(request, "animais/detalhes_animal.html", contexto)

Trecho de polls/templates/animais/lista_categoria.html. O modelo Animal não possui o campo nome, então o filtro |upper foi aplicado ao nome legível da espécie (get_especie_display).

{% if lista_itens %}
<ul>
{% for item in lista_itens %}
<li>{{ item.get_especie_display|upper }} — {{ item.descricao }} — <a href="{% url 'polls:detalhes_animal' item.pk %}">Ver detalhes</a></li>
{% endfor %}
</ul>
{% else %}
<p>Nenhum registro encontrado.</p>
{% endif %}

a) O {% if lista_itens %} verifica se a lista não está vazia; se estiver, o {% else %} exibe "Nenhum registro encontrado.".
b) O {% for %} percorre a lista e cria um <li> para cada item dentro de um <ul>.
c) {{ item.get_especie_display|upper }} exibe o nome em letras maiúsculas.
d) {% url 'polls:detalhes_animal' item.pk %} usa o namespace "polls", o nome da rota e o ID do item.

b) View em polls/views.py:

def lista_categoria(request, nome_categoria):
    if nome_categoria == "gato":
        codigo = "GAT"
    elif nome_categoria == "cachorro":
        codigo = "CAC"
    elif nome_categoria == "outro":
        codigo = "OUT"
    else:
        codigo = ""

    animais = models.Animal.objects.filter(especie=codigo, adotado=False)
    contexto = {"lista_itens": animais, "categoria": nome_categoria}
    return render(request, "animais/lista_categoria.html", contexto)
